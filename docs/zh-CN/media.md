# 媒体

> 本文译自 [media.md](../media.md)，对应提交 `827f08e77c66`。译文与英文版不一致时，以英文版为准。本译文尚未经过母语者审校，欢迎提交修正。

`tele` 在聊天中直接显示什么、自己播放什么、交给外部程序处理什么。相关设置都位于 `photos:` 下，见 [configuration.md](configuration.md#photos)。

<a id="photos"></a>
## 图片

在 kitty、Ghostty 和 iTerm2 3.7.0 及以上版本中，图片通过 Kitty 图形协议以高画质直接显示在聊天中，其他终端则以 ANSI 字符块画回退显示。tmux 和 screen 不转发该协议，因此在它们中间图片显示为字符块画。

按 `o` 在应用内的查看器中打开原画质图片，边框上显示发送者和时间；按 `O` 在外部查看器中打开。

<a id="voice-messages"></a>
## 语音消息

显示带时长的振幅波形，按 `p` 在应用内播放，并有移动的播放位置。

所有平台上的播放都不依赖 cgo：Opus/Ogg 用纯 Go 解码，声音在 macOS 和 Windows 上通过 `oto` 输出，在 Linux 上通过 PulseAudio/PipeWire 协议输出。在 Linux 上需要有正在运行的 PulseAudio 或 PipeWire 服务器，桌面环境默认就是如此。

<a id="video-and-round-video-кружки"></a>
## 视频和圆形视频

聊天中显示带时长的缩略图预览；圆形视频显示为圆形。按 `o` 打开视频。在 Kitty 图形模式下，如果有 `ffmpeg`，视频会在现有弹窗中静音播放：空格暂停或继续，方向键切换相册项目，`o` 切换到外部播放器，escape 关闭弹窗。在其他终端（包括 Foot）中使用外部播放器。

对于已知大小的视频，播放采用渐进式传输：持有账号连接的进程通过私有、临时的 loopback URL 提供所请求的 Telegram 字节范围。无需创建完整的临时视频文件，即可在整个文件下载完成前开始播放；容器元数据可以从文件末尾读取。不要求传入的 `SupportsStreaming` 标记。小型、有上限的内存缓存避免重复读取，不占用磁盘缓存。

在 Linux 上，如果 `PATH` 中存在 `mpv`，外部播放（包括按 `O`）会使用它。在 mpv 中跳转播放位置会直接请求所需的字节范围。应用内弹窗保留现有控制，不新增跳转或声音。在其他平台，或 Linux 没有 mpv 时，仍先下载完整文件，再用系统播放器打开；不会将 HTTP URL 交给 `xdg-open`。文件大小未知、打开时传输失败或播放器失败时，也会回退到完整的本地文件。

关闭弹窗或 mpv、打开其他视频或照片、窗口断开连接或退出都会取消流。Tele 管理它启动的 mpv 进程。流会在四小时后过期。暂停会通过反压限制读取；播放器和套接字可能预读少量数据，但不会保存整个文件。

显式 Download 操作保持独立：仍通过现有下载器将完整文件保存到 Downloads 目录，并显示进度。

<a id="gifs"></a>
## GIF

在聊天中显示带 `GIF` 标记的静态缩略图。在 Kitty 图形模式下，选中的 GIF 会在原位静音循环播放。这需要 `ffmpeg`，见下文。

<a id="audio-music"></a>
## 音频（音乐）

显示表演者、标题和时长。其他媒体类型显示为带标签的占位符。

<a id="sending-media"></a>
## 发送媒体

用 `u` 附加磁盘上已有的文件（图片、视频、语音、音乐、文档），发送前确认以哪种类型发送。再按一次 `u` 可以添加更多文件：它们会作为一个相册发送，图片和文档会自动分成不同的相册。

<a id="recording-is-out-of-scope"></a>
## 不支持录制

`tele` 可以*发送*预先录好的音频或视频文件，但不能在应用内**录制**语音消息或圆形视频，也不支持实时语音或视频通话。作为不依赖 cgo 的终端客户端，它没有采集麦克风或摄像头的能力。这是架构上的边界，而不是路线图上缺少的功能。

<a id="optional-dependency-ffmpeg"></a>
## 可选依赖：`ffmpeg`

在 `PATH` 中安装 `ffmpeg`（连同 `ffprobe`）以启用应用内视频播放、聊天中的 GIF 播放，以及发送视频时的时长、尺寸和缩略图。安装 `mpv` 可在 Linux 上启用渐进式外部视频播放。这些依赖都是可选的：没有 ffmpeg，GIF 保持静态，视频仍可发送（Telegram 在服务器端生成预览）；没有 mpv，系统播放器会打开完整下载的文件。
